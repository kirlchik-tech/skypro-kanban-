# Skypro Kanban

**Skypro Kanban** — учебный React-проект в формате современной kanban-доски для управления задачами. Приложение поддерживает авторизацию, работу с задачами через API, переключение светлой и тёмной темы, подробный просмотр карточек, редактирование, удаление и drag-and-drop перемещение задач между колонками.

Проект собран на **React + Vite** и оформлен с упором на аккуратный интерфейс, понятные пользовательские состояния и хорошую структуру кода.

---

## Возможности

### Авторизация пользователя

В приложении реализован полноценный пользовательский сценарий:

- регистрация нового аккаунта;
- вход по логину и паролю;
- хранение пользователя и токена авторизации;
- защищённые маршруты;
- выход из аккаунта через подтверждающее модальное окно;
- отображение имени и почты текущего пользователя в меню профиля.

Авторизация вынесена в `AuthContext`, поэтому компоненты не работают напрямую с `localStorage` и не дублируют логику пользователя.

---

### Kanban-доска

Основной экран — это kanban-доска с колонками по статусам:

- `Без статуса`;
- `Нужно сделать`;
- `В работе`;
- `Тестирование`;
- `Готово`.

Задачи автоматически распределяются по колонкам в зависимости от своего статуса. Если задач нет, пользователь видит понятное состояние: **«Новых задач нет»**, а не пустой экран или ошибку.

---

### Создание задач

Пользователь может создать новую задачу через отдельное модальное окно.

При создании можно указать:

- название задачи;
- описание;
- категорию: `Web Design`, `Research`, `Copywriting`;
- срок исполнения через календарь.

Перед отправкой данные проходят проверку:

- нельзя отправить пустое название;
- нельзя отправить поля, состоящие только из пробелов;
- нельзя создать задачу без описания;
- нельзя создать задачу без выбранной даты.

Ошибки показываются прямо в интерфейсе и дополнительно дублируются через toast-уведомления.

---

### Просмотр и редактирование задачи

При клике по карточке открывается окно подробного просмотра задачи.

В режиме просмотра пользователь видит:

- название;
- категорию;
- статус;
- описание;
- срок исполнения.

Поля в этом режиме неактивны. Чтобы изменить данные, пользователь нажимает **«Редактировать задачу»**, после чего карточка переключается в режим редактирования.

В режиме редактирования можно изменить:

- название задачи;
- описание;
- статус;
- дату исполнения.

Также доступно удаление задачи. После удаления карточка сразу исчезает с доски.

---

### Drag-and-drop перемещение карточек

Одна из ключевых возможностей проекта — перемещение карточек между колонками с помощью drag-and-drop.

Пользователь может зажать карточку, перетащить её в другую колонку и отпустить. При этом:

- колонка, над которой находится карточка, визуально подсвечивается;
- появляется область, показывающая, куда будет помещена задача;
- после отпускания карточки статус задачи автоматически обновляется;
- изменение сохраняется через API;
- пользователь получает уведомление об успешном переносе.

Функция реализована через `@dnd-kit/core`, поэтому взаимодействие выглядит плавно и современно.

---

### Светлая и тёмная тема

В приложении реализована смена темы через `ThemeProvider`.

Пользователь может переключить тему в меню профиля. Выбор сохраняется в `localStorage`, поэтому после перезагрузки страницы выбранная тема остаётся активной.

Тёмная тема проработана не только для общего фона, но и для основных элементов интерфейса:

- header;
- карточки задач;
- модальные окна;
- календарь;
- меню пользователя;
- кнопки;
- статусы;
- категории задач.

Цвета категорий адаптированы под тему. Например, в тёмной теме у категорий используется яркий фон и более мягкий цвет текста, чтобы сохранить читаемость и визуальный стиль.

---

### Toast-уведомления

Для продвинутых оповещений используется **React-Toastify**.

Уведомления появляются при:

- успешном создании задачи;
- успешном сохранении изменений;
- удалении задачи;
- переносе карточки между колонками;
- ошибках сервера;
- ошибках заполнения формы;
- входе и регистрации пользователя.

Toast-уведомления автоматически подстраиваются под текущую тему приложения.

---

### Обработка ошибок и состояний

В проекте предусмотрена обработка основных пользовательских и сетевых сценариев:

- ошибки авторизации;
- ошибки регистрации;
- ошибки создания задачи;
- ошибки редактирования;
- ошибки удаления;
- ошибки при падении сервера;
- состояние загрузки;
- пустой список задач;
- страница 404.

При проблемах с API пользователь получает понятное сообщение, а не техническую ошибку из консоли.

---

### Страница 404

Для несуществующих маршрутов реализована отдельная страница 404 в стиле приложения.

На странице есть:

- сообщение о том, что страница не найдена;
- визуальное оформление в общей стилистике проекта;
- ссылка для возврата на главную страницу.

## Технологии

Проект построен на современном frontend-стеке:

- **React** — интерфейс и компонентная архитектура;
- **Vite** — быстрая сборка и dev-сервер;
- **React Router DOM** — маршрутизация и защищённые страницы;
- **Styled Components** — стилизация компонентов и темы;
- **Context API** — управление авторизацией, задачами, модальными окнами и темой;
- **React-Toastify** — уведомления;
- **@dnd-kit/core** — drag-and-drop перемещение задач;
- **REST API** — получение, создание, редактирование и удаление задач.

---

## Архитектура

Логика приложения разделена по контекстам:

### `AuthContext`

Отвечает за:

- текущего пользователя;
- авторизацию;
- регистрацию;
- выход из аккаунта;
- состояние авторизации.

### `TaskContext`

Отвечает за:

- хранение списка задач;
- загрузку задач с сервера;
- создание задачи;
- редактирование задачи;
- удаление задачи;
- обновление списка после операций.

### `ModalContext`

Отвечает за:

- открытие модального окна создания задачи;
- открытие просмотра задачи;
- открытие окна подтверждения выхода;
- хранение текущей выбранной задачи.

### `ThemeModeContext`

Отвечает за:

- текущую тему;
- переключение темы;
- сохранение выбранной темы в `localStorage`;
- передачу темы в `ThemeProvider`.

---

## Работа с API

Приложение работает с API Kanban и User.

Основные операции:

- получение списка задач;
- создание задачи;
- редактирование задачи;
- удаление задачи;
- регистрация пользователя;
- авторизация пользователя.

Для защищённых запросов используется Bearer-токен, который сохраняется после входа или регистрации.

## Установка и запуск

Склонируйте репозиторий и установите зависимости:

```bash
npm install
```

Запустите проект в режиме разработки:

```bash
npm run dev
```

Соберите production-версию:

```bash
npm run build
```

Запустите предпросмотр production-сборки:

```bash
npm run preview
```

## Основные сценарии использования

1. Пользователь регистрируется или входит в аккаунт.
2. После входа открывается kanban-доска.
3. Пользователь создаёт задачу через кнопку **«Создать новую задачу»**.
4. Задача появляется в колонке **«Без статуса»**.
5. Пользователь может открыть карточку, посмотреть детали и перейти к редактированию.
6. Статус можно изменить вручную в окне редактирования или просто перетащить карточку в нужную колонку.
7. При каждом важном действии приложение показывает уведомление.
8. Пользователь может переключить тёмную тему в меню профиля.
